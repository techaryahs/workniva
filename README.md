# WorkNiva — Enterprise On-Demand Workspaces

WorkNiva is an enterprise-grade platform for booking on-demand professional workspaces, executive meeting suites, boardrooms, and focus studios with instant keyless access, real-time availability, and frictionless billing.

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion, Lucide Icons
- **Backend & Auth**: Supabase (PostgreSQL, Realtime, Row Level Security)
- **Payments**: Razorpay Gateway Integration

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
